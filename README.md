# ติดตามน้ำท่วมประเทศไทย

เว็บไซต์อ่านอย่างเดียว สำหรับดูฝน ระดับน้ำ เรดาร์ฝน น้ำท่วมถนน และทางหลวงที่น้ำท่วม
จากแหล่งข้อมูลทางการ เพื่อใช้ประกอบการตัดสินใจก่อนเดินทาง ไม่ต้องล็อกอิน ไม่รับข้อมูลจากผู้ใช้

**เว็บไซต์จริง: https://flood-monitor.flood-monitor.workers.dev**

> ใช้ประกอบการตัดสินใจเท่านั้น โปรดตรวจสอบประกาศทางการอีกครั้ง
> เบอร์ฉุกเฉิน: 1669 (เจ็บป่วยฉุกเฉิน) · 1784 (ปภ.) · 1555 (กทม.)

## วิธีค้นหาสถานที่

ช่อง **ค้นหาสถานที่** อยู่ที่หน้าที่ประจำ บนแผนที่ และในกล่องเพิ่มสถานที่ พิมพ์ได้ทั้ง

- ชื่อตำบล อำเภอ จังหวัด เช่น `ธาตุพนม` หรือ `บางกะปิ กรุงเทพ` (ขึ้นทันที ใช้ได้แม้ออฟไลน์)
- ชื่อสถานที่ เช่น โรงแรม คอนโด หมู่บ้าน โรงเรียน วัด ตลาด (รอ 1 ถึง 4 วินาที) ใช้ Longdo Map เป็นหลัก
  และ OpenStreetMap เป็นตัวสำรอง ต้องตั้ง secret `LONGDO_API_KEY` (สมัครฟรีที่ map.longdo.com) ถ้าไม่ตั้งจะใช้ OpenStreetMap อย่างเดียว

แตะผลลัพธ์เพื่อดูฝน ระดับน้ำ และพยากรณ์ใกล้จุดนั้น แล้วกด **บันทึกเป็นที่ประจำ** ได้เลย

บนหน้าแผนที่ สวิตช์ **แผนที่ละเอียด** (เปิดไว้เป็นค่าเริ่มต้น) แสดงชื่ออาคาร ร้านค้า และซอยเมื่อซูมเข้า ปิดได้ถ้าต้องการแผนที่เรียบ

## วิธีเพิ่มที่ประจำ

1. เปิดหน้า **ที่ประจำ** แล้วกด **เพิ่มสถานที่**
2. ตั้งชื่อ เช่น "บ้านคุณยาย" และเลือกประเภท (บ้าน / ที่ทำงาน / โรงเรียน / อื่นๆ)
3. เลือกตำแหน่งด้วยวิธีใดวิธีหนึ่ง
   - **พิมพ์ค้นหา** ในช่องค้นหาแล้วแตะผลลัพธ์
   - **ใช้ตำแหน่งปัจจุบัน** (เครื่องจะถามขออนุญาตใช้ตำแหน่ง)
   - **เลือกบนแผนที่** แล้วแตะจุดที่ต้องการ จากนั้นกด **ใช้ตำแหน่งนี้**
4. กด **บันทึก**

อีกวิธี: เปิดหน้า **แผนที่** แตะจุดใดก็ได้ แล้วกด **บันทึกเป็นที่ประจำ**

สถานที่ถูกเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์
จึงต้องเพิ่มใหม่ในแต่ละเครื่อง และจะหายถ้าล้างข้อมูลเบราว์เซอร์
แก้ไขหรือลบได้จากปุ่มในหน้ารายละเอียดของสถานที่นั้น

## แจ้งเตือนฝนทาง LINE

ส่งถึงทุกคนที่แอดบัญชี LINE ของครอบครัวเป็นเพื่อน 2 แบบ:

- **สรุปเวลา 08:00 และ 18:00 น.** พยากรณ์ 12 ชั่วโมงข้างหน้าของทุกพื้นที่ ส่งเฉพาะวันที่มีพื้นที่ใดเสี่ยงฝน
  (ถ้าส่งไม่ได้ตรงเวลาเพราะเพิ่งส่งไปไม่ถึง 3 ชั่วโมง จะส่งภายใน 2 ชั่วโมงหลังจากนั้น)
- **เตือนด่วนระหว่างวัน** เมื่อพยากรณ์มีโอกาสฝนตั้งแต่ 60%, ฝนหนัก (ตั้งแต่ 10 มม./ชม.) หรือพายุฝนฟ้าคะนอง
  ภายใน 2 ชั่วโมง และสรุปรอบล่าสุดยังไม่ได้บอกฝนช่วงนั้นของพื้นที่นั้น

- พื้นที่: มีนบุรี · บางเขน (พหลโยธิน) · ห้วยขวาง (รัชดา) · รามอินทรา · เกษตร–รัชโยธิน · ลับแล อุตรดิตถ์ ·
  นิคมพัฒนา · เมืองระยอง · ปลวกแดง
- กติกา (สรุปและเตือนด่วนรวมกัน): วันละไม่เกิน 2 ครั้ง ห่างกันอย่างน้อย 3 ชั่วโมง เดือนละไม่เกิน 48 ครั้ง
  (LINE ฟรี 300 ข้อความ/เดือน นับตามจำนวนผู้รับ: 6 คน × 48 = 288 เหลือสำรอง 12 ไว้แจ้งว่าโควตาหมด)
- ดูจำนวนที่ส่งไปแล้วและสถานะ token ได้ที่หน้า **สถานะข้อมูล**

### ตั้งค่าครั้งแรก

1. สร้างบัญชี LINE Official Account ที่ https://manager.line.biz (ใช้บัญชี LINE ส่วนตัวล็อกอิน เลือกแพ็กเกจฟรี)
2. ใน LINE Official Account Manager ไปที่ **ตั้งค่า → Messaging API** แล้วกด **เปิดใช้ Messaging API**
   (ระบบจะให้สร้างหรือเลือก Provider ตั้งชื่ออะไรก็ได้)
3. เปิด https://developers.line.biz/console เลือก Provider และ channel ที่เพิ่งสร้าง → แท็บ **Messaging API**
   → หัวข้อ **Channel access token (long-lived)** กด **Issue** แล้วคัดลอก token
4. เพิ่มบรรทัดนี้ในไฟล์ `.dev.vars` (ไฟล์เดียวกับ token ของกรมอุตุฯ):

   ```
   LINE_CHANNEL_ACCESS_TOKEN=วางtokenตรงนี้
   ```

   แล้วตั้งเป็น secret บน Cloudflare (หรือบอกให้ Claude ทำให้):

   ```
   sed -n 's/^LINE_CHANNEL_ACCESS_TOKEN=//p' .dev.vars | npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
   ```

5. ให้ทุกคนในครอบครัวแอดบัญชีเป็นเพื่อน: ในแท็บ Messaging API มี QR code ให้สแกน
6. ปิดข้อความตอบกลับอัตโนมัติ (ไม่บังคับ): LINE Official Account Manager → **ตั้งค่าการตอบกลับ**

### ส่งข้อความเองจากหน้าผู้ดูแล

เปิด https://flood-monitor.flood-monitor.workers.dev/admin (หรือลิงก์ท้ายหน้า "วิธีอ่าน") แล้วเข้าสู่ระบบด้วยชื่อผู้ใช้ `admin`
ผู้ชมทั่วไปไม่ต้องเข้าสู่ระบบ

- กด **ใช้ข้อความจากพยากรณ์ตอนนี้** เพื่อสร้างข้อความสรุปทั้ง 6 จุด แก้ไขได้ก่อนส่ง หรือพิมพ์เอง
- เลือก **ทุกคนที่แอดเพื่อน** หรือ **เลือกคน** หน้าจอบอกว่าจะใช้กี่ข้อความและเหลือเท่าไร
- ข้อความที่ส่งเองใช้โควตา 300 ร่วมกับแจ้งเตือนอัตโนมัติ ระบบจะลดเพดานแจ้งเตือนอัตโนมัติตามที่ใช้ไป
- รายชื่อสำหรับ "เลือกคน" มาจาก webhook: ใครแอดเพื่อนหรือพิมพ์ในแชตบอท ระบบจะจำชื่อไว้
  (LINE ไม่ให้บัญชีที่ยังไม่ยืนยันดึงรายชื่อเพื่อนทั้งหมด) แต่ละคนจะได้ข้อความตอบกลับว่าลงทะเบียนแล้ว
- กรอกรหัสผิด 5 ครั้งใน 15 นาที จะถูกล็อกชั่วคราว
- เปลี่ยนรหัสผ่าน: `npx wrangler secret put ADMIN_PASSWORD`

secret ที่หน้าผู้ดูแลใช้: `ADMIN_PASSWORD`, `SESSION_SECRET` (สุ่มไว้แล้ว), `LINE_CHANNEL_SECRET`
(ใช้ตรวจว่าคำขอ webhook มาจาก LINE จริง)

### ปรับรูปแบบข้อความ

หน้า `/admin` → แท็บ **รูปแบบข้อความ** แก้ได้ทั้ง "สรุป 08:00 / 18:00" และ "เตือนด่วน"

- แก้ไอคอน หัวข้อ บรรทัดของแต่ละระดับ (พายุ / ฝนหนัก / โอกาสฝนสูง / ยังไม่ถึงเกณฑ์) และข้อความเพิ่มเติม
- แตะตัวแปร เช่น `{พื้นที่}` `{ช่วงเวลา}` `{โอกาส}` หรือ emoji เพื่อแทรกที่ตำแหน่งเคอร์เซอร์
- ด้านขวา (บนมือถืออยู่ด้านล่าง) เป็นตัวอย่างห้องแชต LINE เลือกขนาดจอได้ (iPhone SE, iPhone 15, Pro Max,
  Android, iPad) พร้อมตัวอย่างการแจ้งเตือนบนหน้าจอล็อก ใช้พยากรณ์จริงหรือ "ตัวอย่างทุกแบบ"
- ระบบนับความยาวกรณียาวที่สุด (ทุกพื้นที่เข้าเกณฑ์) เทียบกับเพดาน 5,000 ตัวอักษรของ LINE และไม่ให้บันทึกถ้าเกินหรือใช้ตัวแปรผิด
- **ส่วนท้ายแก้ไม่ได้**: แหล่งที่มา ลิงก์ดูรายละเอียด จำนวนครั้งของเดือน และ "ใช้ประกอบการตัดสินใจเท่านั้น…"
- **ส่งทดสอบ** ถึงคนที่เลือกคนเดียว (ใช้ 1 ข้อความ) เพื่อดูของจริงบนมือถือ เพราะฟอนต์และ emoji ในตัวอย่างมาจากเบราว์เซอร์ที่เปิดอยู่
- **คืนค่าเริ่มต้น** ได้ทุกเมื่อ

### เปลี่ยนพื้นที่หรือกติกา

แก้ `ALERT_AREAS` และ `ALERT_LIMITS` ใน [shared/alerts.ts](shared/alerts.ts) ถ้าจำนวนคนเปลี่ยน
ให้แก้ `ALERT_RECIPIENTS` ใน `wrangler.toml` แล้ว `npm run deploy` ระบบจะคำนวณเพดานต่อเดือนใหม่ให้เอง

## วิธีอ่านสี

| สัญลักษณ์ | ความหมาย |
|---|---|
| วงกลมสีเขียว "ปกติ" | ค่าอยู่ในเกณฑ์ปกติของหน่วยงานเจ้าของข้อมูล |
| สามเหลี่ยมสีเหลือง "เฝ้าระวัง" | สูงกว่าปกติ เช่น ฝนหนัก น้ำมาก น้ำท่วมขังเล็กน้อย |
| แปดเหลี่ยมสีส้มแดง "อันตราย" | เช่น ฝนหนักมาก น้ำล้นตลิ่ง น้ำท่วมถนนเกิน 10 ซม. ทางผ่านไม่ได้ |
| สีเทา "ข้อมูลไม่เป็นปัจจุบัน" หรือ "ไม่มีข้อมูล" | ข้อมูลเก่าเกินเกณฑ์ หรือไม่มีเซนเซอร์ |

"ไม่มีข้อมูล" ไม่ได้แปลว่าไม่ท่วม เว็บไซต์นี้ไม่เคยยืนยันว่าพื้นที่ใดไม่มีน้ำท่วม

เกณฑ์ที่ถือว่าข้อมูลไม่เป็นปัจจุบัน: เซนเซอร์น้ำท่วมถนน 60 นาที · สถานีฝนและระดับน้ำ 3 ชั่วโมง ·
เรดาร์ 30 นาที · พยากรณ์ 3 ชั่วโมง · รายงานทางหลวง 24 ชั่วโมง
(แก้ค่าได้ที่ `STALE_MINUTES` ใน [shared/sources.ts](shared/sources.ts))

## วิธี deploy ใหม่

ต้องมี Node.js 20 ขึ้นไป และล็อกอิน Cloudflare ไว้แล้ว (`npx wrangler login`)

```
npm install          # ครั้งแรกเท่านั้น
npm test             # ทดสอบตัวแปลงข้อมูลกับไฟล์ตัวอย่างใน fixtures/
npm run deploy       # build แล้ว deploy ขึ้น Cloudflare
```

ถ้าแก้โครงสร้างฐานข้อมูล (เพิ่มไฟล์ใน `migrations/`) ให้รันก่อน deploy:

```
npm run db:migrate:remote
```

### token ของกรมอุตุนิยมวิทยา

พยากรณ์ของ TMD ใช้ token ที่เก็บเป็น secret ชื่อ `TMD_API_TOKEN` (ตั้งไว้แล้ว)
ถ้า token หมดอายุ พยากรณ์จะสลับไปใช้ Open-Meteo เองและหน้าสถานะข้อมูลจะแจ้งว่า TMD ขัดข้อง
ตั้งค่าใหม่ด้วยคำสั่งนี้ แล้ววาง token เมื่อถูกถาม:

```
npx wrangler secret put TMD_API_TOKEN
```

อย่าใส่ token ลงในไฟล์ที่ commit ไฟล์ `.dev.vars` (สำหรับทดสอบในเครื่อง) อยู่ใน `.gitignore` แล้ว

### ทดสอบในเครื่อง

```
npm run db:migrate:local     # ครั้งแรกเท่านั้น
npm run dev                  # เปิด http://localhost:8787
curl "http://localhost:8787/cdn-cgi/handler/scheduled?cron=manual"   # สั่งดึงข้อมูลทุกแหล่งหนึ่งรอบ
```

## ข้อจำกัดที่ควรรู้

1. **ฝนและระดับน้ำ (ThaiWater) เบราว์เซอร์ของผู้ชมเป็นผู้ดึงเอง** ThaiWater ปฏิเสธคำขอจาก
   เซิร์ฟเวอร์ของ Cloudflare ทุกครั้ง (ตอบ 429) จึงให้เบราว์เซอร์ดึงตรงแทน ผลคือ
   ใช้อินเทอร์เน็ตราว 0.8 MB ทุก 10 นาทีที่เปิดเว็บ, ThaiWater เห็นการเชื่อมต่อจากเครื่องผู้ชมเอง
   และถ้า ThaiWater ปิดการเข้าถึงข้ามเว็บไซต์ สองชั้นข้อมูลนี้จะขึ้นว่า "แหล่งข้อมูลขัดข้อง"
2. **เซนเซอร์น้ำท่วมถนน กทม. และรายงานทางหลวง อัปเดตเมื่อมีผู้เปิดเว็บ** สองแหล่งนี้รับเฉพาะ
   คำขอจากในประเทศไทย แต่งานตั้งเวลา (cron) ของ Cloudflare รันจากต่างประเทศ จึงให้ Worker
   ดึงตอนมีผู้ชมในไทยเปิดเว็บ (ไม่เกิน 1 ครั้งต่อ 10 นาที) ถ้าไม่มีใครเปิดเว็บนาน ข้อมูลจะเป็นสีเทา
   จนกว่าจะมีคนเปิด และจะอัปเดตภายในไม่กี่วินาที กราฟย้อนหลังของเซนเซอร์ถนนจึงมีเฉพาะช่วงที่มีคนใช้เว็บ
3. **กล้อง CCTV กทม. แสดงบนแผนที่ไม่ได้** เว็บไซต์ bmatraffic.com ติดต่อจาก Cloudflare ไม่ได้
   และไม่อนุญาตให้นำภาพไปแสดงที่อื่น เว็บจึงให้ลิงก์ไปเปิดที่เว็บไซต์ต้นทาง กล้องของกรมทางหลวงก็เป็นลิงก์เช่นกัน
4. **สถานีฝนและระดับน้ำใช้เกณฑ์ 3 ชั่วโมง ไม่ใช่ 60 นาที** เพราะหลายหน่วยงานส่งข้อมูลรายชั่วโมง
   และ ThaiWater เผยแพร่ช้ากว่าเวลาตรวจวัด 1.5 ถึง 2.5 ชั่วโมง ถ้าใช้ 60 นาที สถานีเกินครึ่งจะเป็นสีเทาตลอด
   ทุกค่ายังแสดงเวลาตรวจวัดจริงกำกับ
5. **เรดาร์อาจเป็นสีเทาเป็นช่วงสั้นๆ** กรมอุตุฯ ออกภาพทุก 15 นาทีและเผยแพร่ช้าราว 10 ถึง 20 นาที
   เมื่อรวมรอบดึง 10 นาที ภาพอาจเก่าเกิน 30 นาทีได้ชั่วคราว
6. **ไม่พบเอกสารอนุญาตให้แสดงภาพเรดาร์ของกรมอุตุฯ ซ้ำ** เว็บแสดงภาพโดยไม่ดัดแปลง พร้อมชื่อและลิงก์ต้นทาง
   หากต้องการความชัดเจนควรสอบถามกรมอุตุนิยมวิทยา
7. **รายงานทางหลวงมาจาก endpoint ที่ไม่มีเอกสาร** (ระบบเดียวกับแดชบอร์ดสาธารณะของกรมทางหลวง)
   อาจเปลี่ยนรูปแบบได้โดยไม่แจ้ง ถ้าเปลี่ยน เว็บจะแสดงว่าแหล่งข้อมูลขัดข้องและไม่เดาค่าเอง
8. **TMD ไม่มีค่าโอกาสฝนรายชั่วโมง** กราฟจึงใช้แท่งปริมาณฝนจาก TMD และเส้นโอกาสฝนจาก Open-Meteo
   โดยติดป้ายแหล่งที่มาแยกกัน
9. **พยากรณ์ TMD ทดสอบในเครื่องไม่ได้** runtime ของ `wrangler dev` ต่อกับเซิร์ฟเวอร์ TMD ไม่ได้
   (ชุดเข้ารหัส TLS รุ่นเก่า) ในเครื่องจึงเห็น Open-Meteo เสมอ บนเว็บจริงใช้ TMD ได้ปกติ
10. **ข้อมูลบางส่วนมีเฉพาะภาษาไทย** เช่น ชื่อลำน้ำ ชื่อเหตุทางหลวง แม้เลือกภาษาอังกฤษ
11. **แผนที่ 3 มิติไม่มีความสูงของภูมิประเทศ** มีเฉพาะการเอียงมุมมองและอาคาร
    และจะปิดเองถ้าเครื่องแสดงผลช้า
12. **การค้นหาชื่อสถานที่ใช้บริการ Photon (ข้อมูล OpenStreetMap)** คำค้นถูกส่งผ่านเซิร์ฟเวอร์ของเว็บนี้
    ไปยัง Photon ชื่อบางแห่งอาจไม่มีหรือสะกดต่างจากที่คุ้นเคย และถ้าบริการล่มจะค้นได้เฉพาะตำบล อำเภอ จังหวัด
13. **แจ้งเตือน LINE อาศัยพยากรณ์เท่านั้น** (Worker ดึงฝนจากสถานี ThaiWater ไม่ได้) อาจมีฝนโดยไม่ได้เตือน
    หรือเตือนแล้วฝนไม่ตก และเมื่อครบเพดานของเดือนจะหยุดเตือนจนถึงวันที่ 1 ของเดือนถัดไป
14. **ทุกอย่างอยู่บนแพ็กเกจฟรี** ของ Cloudflare หากมีผู้ใช้จำนวนมากอาจชนโควตารายวัน
